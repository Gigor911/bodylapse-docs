# Logos

The mark is a fanned two-card stack, the front card carrying two text bars. All files are rendered from one vector source by `scripts/generate-brand-assets.swift`; use them as supplied and never redraw the mark.

- `app-icon.png`: iPhone/iPad icon, light appearance (plum cards on a blush ground), 1024².
- `app-icon-dark.png`: dark appearance (pink cards on aubergine), 1024².
- `app-icon-tinted.png`: tinted appearance (grayscale, the system tints it), 1024².
- `app-icon-mac.png`: macOS icon inside the macOS template (824pt rounded square with drop shadow), 1024².
- `launch-logo.png`: the transparent mark for light grounds (`canvasBG` `#FBF4F2`), 360².
- `launch-logo-dark.png`: the transparent mark for dark grounds (`#17111A`), 360².

The icons and launch logo stay plum in every palette.
